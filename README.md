# Repository สำหรับส่งงานคอร์ส GenAI DevSecOps Camp

Repository นี้ใช้สำหรับเก็บงานและการบ้านที่ได้ทำภายในคอร์ส GenAI DevSecOps Camp

ลิงก์คอร์ส: https://genai-devsecops-camp.vercel.app/

## วัตถุประสงค์
Repository นี้เป็นพื้นที่สำหรับจัดเก็บผลงานที่ได้ฝึกปฏิบัติในแต่ละสัปดาห์ของคอร์ส โดยมีจุดประสงค์เพื่อ
- เก็บไฟล์งานและการบ้านที่ทำเสร็จแล้ว
- ไว้สำหรับส่งงานและตรวจทานความก้าวหน้า
- สะท้อนการเรียนรู้จากแต่ละบทที่ฝึกปฏิบัติ

## โครงสร้างของ Repository
- `week1/` — เนื้อหาหลักของ Week 1
  - `lab3a/` — งานฝึกที่เกี่ยวกับการสร้างหน้าเว็บเบื้องต้น
  - `lab5a/` — งานฝึกสร้างหน้า Personal Profile

## Week 1: ภาพรวม
Week 1 เป็นช่วงเริ่มต้นของการเรียนรู้ด้าน Frontend และ HTML/CSS โดยเน้นเรื่องพื้นฐานดังนี้
- การสร้างโครงสร้างเว็บด้วย HTML
- การจัดรูปแบบหน้าเว็บด้วย CSS
- การออกแบบหน้าเว็บที่เป็น responsive
- การสร้างความรู้เรื่อง Semantic HTML และ accessibility
- การเขียนโปรเจกต์เล็ก ๆ เช่น Personal Profile Page

### ตัวอย่างงานใน Week 1
- `week1/lab5a/index.html` — โครงสร้าง HTML ของหน้าโปรไฟล์ส่วนตัว
- `week1/lab5a/style.css` — การจัดสไตล์และ responsive design

## วิธีเปิดดูเว็บเพจ
เนื่องจากงานใน repo นี้เป็น static page แบบ HTML/CSS จึงสามารถเปิดได้โดยตรงผ่านเบราว์เซอร์ หรือใช้ local server ได้

### วิธีที่ 1: เปิดไฟล์ตรง ๆ
- เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที

### วิธีที่ 2: ใช้ local server
จากโฟลเดอร์ที่ต้องการเปิด ให้รันคำสั่งต่อไปนี้:

```bash
python -m http.server 8000
```

จากนั้นเปิดในเบราว์เซอร์ที่หน้า:

```text
http://localhost:8000
```

## หมายเหตุ
- งานส่วนใหญ่เป็นหน้าเว็บแบบ Static HTML/CSS ไม่ต้องใช้ framework หรือ build tools
- Repository นี้เหมาะสำหรับการส่งงานคอร์สและติดตามความคืบหน้าการเรียนรู้
- ควรจัดโครงสร้างไฟล์ให้ชัดเจนและอ่านง่าย เพื่อความสะดวกในการตรวจและประเมิน
